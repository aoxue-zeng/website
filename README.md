# 星坠圣墟 · Starfall Sanctum

黑暗史诗西幻动作 RPG（纯前端单文件网页游戏）。

> 星神陨落 · 宿命抉择 · 废墟救赎

## 世界观

千年之前，七大星神共治艾瑞亚大陆。部分星神妄图吞噬虚空本源，引发**星陨圣战**——诸神尽数陨落，神血与碎星浸染大地，昔日圣辉文明化为废墟，史称**圣墟时代**。

你是独一无二的**星痕者**：出生时身负星神陨落之印，是大陆唯一能同时接纳星辉圣光与虚空混沌的生灵。打破宿命、重塑世界秩序的关键之人。

- **六大区域**：星辉平原 → 幽影精灵森林 → 霜峰矮人要塞 → 赤红荒原 → 永夜血族领地 → 虚空裂隙边境
- **双阵营宿命抉择**：圣辉守护者（秩序·防御治疗） / 墟影追随者（混沌·爆发吸血），阵营重塑你的技能
- **三幕史诗剧情**：觉醒之始 → 乱世求索 → 宿命终章
- **多结局**：星辉重临 / 墟世新生 / 隐藏结局（集齐 6 枚星核碎片解锁改写宿命的资格）

## 职业

| 职业 | 定位 | 秩序蜕变 | 混沌蜕变 |
|------|------|----------|----------|
| 圣骑士 | 近战坦克/输出 | 圣辉骑士 | 烬灭骑士 |
| 元素法师 | 远程魔法输出 | 星辉法师 | 虚空法师 |
| 游侠 | 远程敏捷输出 | 林间守护者 | 暗影猎影 |
| 秘术师 | 辅助/功能诅咒 | 圣光祭司 | 咒术师 |

## 操作

- **WASD** 移动 · **鼠标** 瞄准 / 左键攻击
- **Q / E / R / F** 星艺（按等级 1/3/6/10 解锁）
- **Shift** 闪避 · **Space** 交互 / 推进对话
- **M** 世界地图 · **C** 角色面板 · **Esc** 暂停
- **1 / 2** 使用生命 / 法力药剂

## 特性

- 无缝区域探索、动态天气、昼夜氛围
- 任务引导（击杀 / 采集 / 精英 / BOSS 讨伐）
- 世界 BOSS 战、精英怪、宝箱与星核碎片收集
- 商店祝福强化、星锻永久升级
- localStorage 自动存档（暂停菜单可手动保存）

## 技术

单文件 `index.html`（Canvas 渲染 + 原生 JS，无任何依赖），直接用浏览器打开即可游玩。

## 本地运行

```bash
# 任意静态服务器，例如：
python -m http.server 8000
# 浏览器访问 http://localhost:8000/星坠圣墟/index.html
```
